KURO OS - LOGO ASSETS

All image assets retain a transparent background.
Recommended use:
- kuro_os_512.webp: website/app UI (smallest, recommended).
- kuro_os_512.png: PNG fallback / systems that require PNG.
- kuro_os_256.png, kuro_os_128.png, kuro_os_64.png, kuro_os_32.png: fixed-size UI icons.
- kuro_os.ico: browser favicon / Windows icon.

The original high-resolution master is available separately.
These are raster exports; a true editable vector SVG is not included.
